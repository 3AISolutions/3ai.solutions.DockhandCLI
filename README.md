# DockhandCLI

Cross-platform .NET 10 command-line client (`dockhand`) for managing multiple
[Dockhand](https://dockermanager.beluggaservices.com/api/docs) installations through their REST APIs:
endpoint aliases, Docker environments, container update checks and updates, an interactive shell,
and JSON output for automation.

> Status: in development. See [docs/ProjectDescription.md](docs/ProjectDescription.md) for the
> requirements and [docs/ApiAnalysis.md](docs/ApiAnalysis.md) for the API analysis and design decisions.
